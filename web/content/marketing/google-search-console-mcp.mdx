Most Google Search Console (GSC) MCP servers are open source, but they take a lot of effort to set up. You need to create a Google Cloud project, enable an API, build an OAuth client, download a `credentials.json`, then keep a local server running. EchoSEO handles the Google connection for you. You sign up, connect your property, and start asking.

## Setup: no Google Cloud project

1. Sign up for EchoSEO — it's free.
2. Go through the onboarding. When prompted, click **Connect Search Console** and pick your property.
3. Add the EchoSEO MCP endpoint to your client (steps below) and approve the EchoSEO login when prompted.

The hosted MCP server URL is:

```txt
https://app.echoseo.ventrarocket.vn/mcp
```

### Claude Code

```bash
claude mcp add --transport http --scope user echoseo https://app.echoseo.ventrarocket.vn/mcp
```

### Claude Desktop

1. Open Settings → Connectors.
2. Click **Add custom connector**.
3. Paste `https://app.echoseo.ventrarocket.vn/mcp`.

### Cursor

1. Open Cursor Settings → Tools & Integrations → MCP Tools.
2. Click **New MCP Server** (this opens `mcp.json`) and add:

```json
{
  "mcpServers": {
    "echoseo": {
      "url": "https://app.echoseo.ventrarocket.vn/mcp"
    }
  }
}
```

### Codex CLI

```bash
codex mcp add echoseo --url https://app.echoseo.ventrarocket.vn/mcp
```

Any other MCP client works the same way: add `https://app.echoseo.ventrarocket.vn/mcp` as a remote server and sign in. Full setup and troubleshooting live in the [MCP docs](/docs/mcp).

### The DIY way (every other GSC MCP)

1. Create a Google Cloud project
2. Enable the Search Console API
3. Configure the OAuth consent screen
4. Create OAuth client credentials
5. Download `credentials.json`
6. Install and run a local MCP server

## What your agent can read

Two read-only tools over the property you connect. Both pull Google's own numbers, and neither uses credits.

**Search performance.** Clicks, impressions, CTR, and average position for your site, sliced by query, page, country, device, and date. Pull up to 16 months of history in a single question.

**URL inspection.** Whether a page is indexed and, if not, why: coverage status, last crawl, the canonical Google chose versus the one you declared, plus mobile and rich-result checks. Up to 10 URLs at a time.

The agent can read and inspect. It cannot change anything in your account.

## What it costs

Nothing. Google doesn't charge you to read your own data, and EchoSEO doesn't charge you either — there is no subscription and no credit system. The research tools on the same MCP endpoint (keyword research, rank tracking, backlinks) need your own DataForSEO key, and DataForSEO bills you directly at their rates. ## FAQ

### What does it cost?

Nothing. The Search Console MCP tools are free, on the hosted app and self-hosted alike. EchoSEO's other tools (keyword research, rank tracking, backlinks) run on your own DataForSEO key through the same endpoint, so that spend sits in your account with your provider, not with us.

### Is it open source?

Yes. EchoSEO is open source, so you can self-host the whole thing for free, including the Search Console MCP. The one-click connection here uses EchoSEO's hosted Google app. If you self-host, you bring your own Google OAuth client, the same Cloud-console step the hosted version saves you. Hosted means no setup; self-hosted means full control.

### Is it read-only?

Yes. EchoSEO requests read-only access (`webmasters.readonly`). Your agent can read performance data and inspect URLs, but it can't change your account.

### Which AI clients work?

Any MCP client, including Claude Code, Claude Desktop, Cursor, Codex, and OpenClaw. Add the EchoSEO MCP endpoint and sign in.

### How fresh is the data?

It's Google's own data, so the most recent few days can be incomplete. History runs back 16 months, the same as the Search Console interface.
